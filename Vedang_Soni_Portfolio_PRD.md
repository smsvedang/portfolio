# Vedang Soni --- Personal Portfolio PRD

## 1. Product Overview

**Product:** Vedang Soni --- Personal Portfolio\
**Type:** Interactive personal portfolio website\
**Visual Identity:** Futuristic Robotics Lab / R&D Control Interface

### Primary Goal

Create a memorable, visually impressive personal website that showcases
Vedang's biotechnology background, technology exposure, innovation
activities, and meaningful hands-on work.

### Core Principle

> **High-tech presentation, honest content.**

The website should feel more like a **personal digital laboratory /
robotics R&D interface** than a conventional student portfolio.

## 12. Animation System

The animation system should create the "robotics lab" feeling without
becoming distracting.

### Page Load

-   Boot sequence
-   Terminal-style text reveal
-   System status indicators
-   Profile photo initialization

### Scroll

-   Sections assemble like modules
-   Cards slide/fade into the interface
-   Connecting lines/nodes animate
-   Status indicators activate

### Cursor

Desktop-only subtle digital cursor interaction: - Small tracking point -
Cards react slightly - Connection lines respond

### Background

-   Technical grid
-   Very subtle moving particles/nodes
-   Circuit-like paths
-   Occasional scanning line

### Micro-interactions

Examples:

``` text
CONNECT → CONNECTING → OPEN
```

Cards can use labels such as:

``` text
MODULE READY
```

Animations should be fast, polished, and premium rather than excessive.

Support `prefers-reduced-motion` for accessibility.

## 15. Content Integrity --- What NOT to Include

The portfolio must remain credible.

Do not include:

-   Fake experience
-   Fake startup claims
-   Fake statistics
-   Unsupported "expert" badges
-   Large lists of half-built projects
-   RakshaX as a finished commercial product
-   Samjho AI as a featured project at this stage
-   Excessive neon/cyberpunk styling
-   Generic portfolio-template language

### Principle

> **Show what was actually built, not everything that was only
> imagined.**

The visual design can be highly futuristic while the content remains
factual and grounded.
